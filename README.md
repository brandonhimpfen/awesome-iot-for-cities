> A curated list of resources for municipal IoT networks, smart city sensor platforms, urban environmental telemetry, smart lighting, and municipal asset monitoring.

Internet of Things (IoT) technologies for cities connect municipal sensor arrays, low-power wide-area networks (LPWAN), intelligent traffic monitors, and environmental sampling nodes to improve urban operations, resource management, and citizen services. This list is intended for smart city architects, IoT engineers, municipal software developers, and urban technology managers.

## Urban Sensor Platforms & Frameworks

Open-source platforms, context brokers, and middleware for aggregating, managing, and acting on municipal IoT streams.

- [FIWARE Context Broker](https://github.com/telefonicaid/fiware-orion) — Open-source core component for managing real-time context information and NGSI data models in smart cities.
- [ThingsBoard](https://github.com/thingsboard/thingsboard) — Open-source IoT platform for device management, data collection, processing, and municipal telemetry visualization.
- [OGC SensorThings API (FROST-Server)](https://github.com/FraunhoferIOSB/FROST-Server) — Open-source implementation of the OGC SensorThings API standard for managing spatial-temporal IoT sensor data.
- [Mainflux](https://github.com/mainflux/mainflux) — Open-source, patent-free IoT cloud platform providing device management and protocol translation for urban scale infrastructure.

## Municipal Telemetry & Connectivity

Low-power wide-area network (LPWAN) protocols, gateway blueprints, and device management systems built for city-wide coverage.

- [The Things Network Stack](https://github.com/TheThingsNetwork/lorawan-stack) — Open-source LoRaWAN network server architecture powering community and municipal long-range sensor deployments.
- [ChirpStack](https://github.com/chirpstack/chirpstack) — Open-source LoRaWAN Network Server stack providing web interfaces and gRPC/MQTT APIs for device management.
- [Eclipse mosquitto](https://github.com/eclipse/mosquitto) — Lightweight open-source MQTT message broker ideal for low-power urban sensor networks and edge nodes.
- [Open-Urban-Gateway](https://github.com/enviro-diy) — Hardware blueprints and firmware for battery and solar-powered municipal wireless nodes.

## Smart Utilities & Lighting Infrastructure

Software controllers, telemetry protocols, and automation engines for connected street lighting, smart water meters, and grid assets.

- [TALQ Consortium Standards](https://github.com/TALQ-Consortium) — Open interface standard for managing heterogeneous smart city device networks and central management software (CMS).
- [Open-Sprinkler-Municipal](https://github.com/OpenSprinkler/OpenSprinkler-Firmware) — Open-source web-connected controller firmware adaptable for public park irrigation and municipal water conservation.
- [GXDLMSDirector](https://github.com/Gurux/Gurux.DLMS.python) — Open-source libraries for communicating with DLMS/COSEM compliant smart meters across city utility grids.

## Urban Environmental Monitoring

Sensor hardware designs, data ingestion pipelines, and alert engines for tracking microclimates, pollution levels, and municipal conditions.

### Air Quality & Noise Sensing

- [Sensor.Community (Luftdaten)](https://github.com/opendata-stuttgart) — Open-source global sensor network and hardware designs for crowdsourced fine dust and air quality monitoring.
- [Noise-Sensing-Node](https://github.com/city-noise) — Embedded sensor stack for acoustic monitoring and urban noise pollution mapping in real time.

### Waste Management & Flood Monitoring

- [Smart-Bin-Telemetry](https://github.com/open-waste-management) — Open-source ultrasonic fill-level sensor firmware for optimizing municipal waste collection routes.
- [Urban-Flood-Warning-System](https://github.com/open-water-level) — IoT ultrasonic and pressure sensor framework for monitoring urban storm drains and river levels.
